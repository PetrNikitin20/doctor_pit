# Моделирование интеллектуальной системы междисциплинарного обучения

Рабочие рукописи П. В. Никитина и Р. И. Гороховой и воспроизводимые исследовательские программы. Редакция от 29 октября 2026 года. Рукописи не обозначаются как принятые или опубликованные статьи. Экспериментов с результатами обучения студентов в этих работах пока нет.

| Рукопись | Предмет результата | Файлы расчёта |
|---|---|---|
| SITITO | Гиперграф предпосылок, происхождение свидетельств и достаточное условие допуска | `research/article` |
| EJCE, русская и английская версии | Паспорт перехода и последствия трёх оценочных правил | `research/ejce` |
| INJOIT | Конечный двухэтапный выбор действий с общими ресурсами и оценкой Sε | `research/injoit` |
| Программные системы: теория и приложения; сохранены редакции ИТВС и ТУСУР | Идентификация двухкомпонентной динамической модели с неизвестной поддержкой | `research/diff_eq` |
| Вестник НГУ: структурная согласованность программы | AND-замыкание, границы независимых дополнений, сертификаты и обновления | `research/structural_consistency` |
| SITITO, Горохова Р. И.: дифференцированное обучение алгоритмам | Методическая модель сложности и поддержки, матрица требований, рубрика, сценарии симулятора | `research/gorokhova_sitito` |

Библиография INJOIT расширена до 25 источников, в том числе двух статей DigiTarin. [Проверка сохранности вычислений](audit/INJOIT_BIBLIOGRAPHY_2026-10-23.md) подтверждает неизменность формул, таблиц и расчётных файлов.

Итоговые редактируемые Word-файлы находятся в [articles](articles). Сводная методология и словарь обозначений – [METHODOLOGY.md](METHODOLOGY.md). Результаты проверки – [audit](audit). Исходный код локального образовательного пилота – [software/cop](software/cop), вместе с миграциями БД, ролями, интерфейсами и тестами. Это снимок публичных исходников MKRmodel; рабочая БД, списки студентов и доступы сюда не входят.

Исследовательские модули ещё не образуют совместно откалиброванный адаптивный оценщик. Сохранённый `beta-independent-v1` использует дробные псевдосчётчики. С 29.10.2026 пилот также содержит отдельный `binary-transition-v1` с бинарными исходами, семействами и δ/m; его готовность к применению требует независимого контрольного банка, протокола и калибровки. Это не обобщение численного оптимизатора INJOIT и не объединение Beta с ОДУ.

Запуск расчётов из корня репозитория:

```bash
node research/article/numerical_experiment.mjs
node research/ejce/decision_simulation.mjs
python tools/validate_research.py
```

Для первых двух расчётов достаточно Node.js; зависимости образовательного веб-приложения им не нужны. Проверка INJOIT использует стандартную библиотеку Python, не изменяет сохранённые временные характеристики и занимает некоторое время на основных задачах.

Для динамического модуля требуются Python 3.12 или новее и зависимости из его `requirements.txt`:

```bash
python -m pip install -r research/diff_eq/requirements.txt
python tools/validate_research.py --ode
python research/diff_eq/experiment.py
```

Последняя команда заново создаёт синтетические JSON/CSV в каталоге модуля. `python research/injoit/experiment.py` повторяет весь численный опыт и замеряет время на текущей машине; время может отличаться от сохранённого исходного замера. Параметр `q` в Python-коде INJOIT соответствует математическому ν, размеру диагностического пакета.

Для редактирования рукописей доступны исходные тексты, библиографические метаданные, изображения и сборщики. [Инструкция по сборке](tools/BUILD.md) отдельно описывает шаблоны журналов и зависимости Windows/Word. Готовые DOCX можно редактировать без запуска сборщиков. Предварительный математический текст `proofs_working.tex` служит исходным материалом доказательств и не является пятой самостоятельной статьёй.

Для EJCE подготовлена английская рукопись: 18 страниц, 24 источника и две новые публикации DigiTarin. Перевод учитывает приложенную авторскую редакцию; прежняя русская версия сохранена. [Вердикт по подаче](audit/EJCE_SUBMISSION_VERDICT_2026-10-23.md) фиксирует соответствие английским требованиям и расхождения между языковыми версиями сайта журнала. Две языковые версии EJCE не являются разными публикациями.

Предыдущая редакция динамической статьи для «Докладов ТУСУР» сохранена в архивных целях. [Заключение по этой редакции](audit/TUSUR_READINESS_2026-10-23.md) относится к прежнему целевому журналу. Текущая редакция подготовлена для «Программных систем: теория и приложения»; отправка не выполнялась.

В `articles/` теперь девять Word-файлов и анонимный PDF для шести исследований, включая исходную редакцию НГУ от 25.10.2026 и методическую статью Р. И. Гороховой. Оформления ИТВС, ТУСУР и ПСТА относятся к одной математической работе, как две языковые версии EJCE относятся к одной образовательной статье. Это альтернативные редакции, а не отдельные результаты для параллельной подачи.

Авторская редакция Гороховой от 29.10.2026 содержит 11 страниц, пять таблиц, одну схему и 27 научных источников, включая две статьи DigiTarin. Педагогический эксперимент выделен в следующий этап. [Заключение готовности](audit/GOROKHOVA_SITITO_READINESS_2026-10-29.md) перечисляет сведения для подтверждения автором, в том числе пока неизвестный ORCID.

## Локальный ИИ-лектор

С 28.10.2026 в [software/math-lecturer](software/math-lecturer) доступен браузерный лектор по математике четырёх работ: 28 занятий с основ, 44 формульных блока, вопросы с привязкой к исходникам, русская озвучка и четыре интерактивные лаборатории. ## Расширение образовательной системы

Публичный снимок [software/cop](software/cop) синхронизирован с MKRmodel: 43 дисциплины, 72 темы, 216 заданий трёх уровней, девять учебных симуляторов, 208 кандидатных переходов и схема из 44 таблиц. Вне алгоритмического курса это авторские стартовые модули для методической экспертизы. Рабочие данные 303 студентов, исходные журналы, пароли и SQL-копии в репозиторий не включены. Облачное размещение отложено.

[Аудит покрытия](software/cop/docs/curriculum-coverage-2026-10-29.json): все 38 компетенций имеют документированные дисциплинарные связи; авторские предложения по заданиям охватывают 25 из 116 индикаторов, остальные 91 требуют разработки. Этот показатель не означает утверждённого покрытия или сформированности компетенций.

[Анализ влияния на статьи](audit/ARTICLE_IMPACT_2026-10-29.md) отделяет расширение приложения от доказанных результатов. Исходные 23 файла комплекта НГУ и Word перенесены без изменения, внутренние 22 контрольные суммы проверены; исходные вычисления не перезапускались и не переименовывались в эксперимент на 43 дисциплинах. [Отчёт импорта](audit/NGU_IMPORT_2026-10-29.json).

Для обновления публичного снимка используется `python tools/sync_cop_snapshot.py --source ПУТЬ_К_MKRmodel --destination software/cop`. Скрипт копирует только файлы зафиксированного Git-коммита, запрещает каталоги private/data/backups/node_modules и сохраняет SHA-256 исходных Git-блоков в SOURCE_SNAPSHOT.json.
