# Моделирование интеллектуальной системы междисциплинарного обучения

Рабочие рукописи П. В. Никитина и воспроизводимые исследовательские программы. Редакция от 23 октября 2026 года. Рукописи не обозначаются как принятые или опубликованные статьи. Экспериментов с результатами обучения студентов в этих работах пока нет.

| Рукопись | Предмет результата | Файлы расчёта |
|---|---|---|
| SITITO | Гиперграф предпосылок, происхождение свидетельств и достаточное условие допуска | `research/article` |
| EJCE, русская и английская версии | Паспорт перехода и последствия трёх оценочных правил | `research/ejce` |
| INJOIT | Конечный двухэтапный выбор действий с общими ресурсами и оценкой Sε | `research/injoit` |
| Доклады ТУСУР, авторская редакция; сохранена версия ИТВС | Идентификация двухкомпонентной динамической модели с неизвестной поддержкой | `research/diff_eq` |

Библиография INJOIT расширена до 25 источников, в том числе двух статей DigiTarin. [Проверка сохранности вычислений](audit/INJOIT_BIBLIOGRAPHY_2026-10-23.md) подтверждает неизменность формул, таблиц и расчётных файлов.

Итоговые редактируемые Word-файлы находятся в [articles](articles). Сводная методология и словарь обозначений – [METHODOLOGY.md](METHODOLOGY.md). Результаты проверки – [audit](audit). Исходный код локального образовательного пилота – [software/cop](software/cop), вместе с миграциями БД, ролями, интерфейсами и тестами. Это снимок публичных исходников MKRmodel; рабочая БД, списки студентов и доступы сюда не входят.

Четыре исследовательских модуля ещё не образуют совместно откалиброванный адаптивный оценщик. Рабочий пилот `beta-independent-v1` использует дробные псевдосчётчики; бинарная исследовательская модель с семействами заданий и распределением риска описывает следующий вариант. Эта граница реализации сохранена в рукописях.

Запуск расчётов из корня репозитория:

```bash
node research/article/numerical_experiment.mjs
node research/ejce/decision_simulation.mjs
python tools/validate_research.py
```

Для первых двух расчётов достаточно Node.js; зависимости образовательного веб-приложения им не нужны. Проверка INJOIT использует стандартную библиотеку Python, не изменяет сохранённые временные характеристики и занимает некоторое время на основных задачах.

Для динамического модуля требуются Python 3.12 или новее и зависимости из его `requirements.txt`:

```bash
python -m pip install -r research/diff_eq/requirements.txt
python tools/validate_research.py --ode
python research/diff_eq/experiment.py
```

Последняя команда заново создаёт синтетические JSON/CSV в каталоге модуля. `python research/injoit/experiment.py` повторяет весь численный опыт и замеряет время на текущей машине; время может отличаться от сохранённого исходного замера. Параметр `q` в Python-коде INJOIT соответствует математическому ν, размеру диагностического пакета.

Для редактирования рукописей доступны исходные тексты, библиографические метаданные, изображения и сборщики. [Инструкция по сборке](tools/BUILD.md) отдельно описывает шаблоны журналов и зависимости Windows/Word. Готовые DOCX можно редактировать без запуска сборщиков. Предварительный математический текст `proofs_working.tex` служит исходным материалом доказательств и не является пятой самостоятельной статьёй.

Для EJCE подготовлена английская рукопись: 18 страниц, 24 источника и две новые публикации DigiTarin. Перевод учитывает приложенную авторскую редакцию; прежняя русская версия сохранена. [Вердикт по подаче](audit/EJCE_SUBMISSION_VERDICT_2026-10-23.md) фиксирует соответствие английским требованиям и расхождения между языковыми версиями сайта журнала. Две языковые версии EJCE не являются разными публикациями.

Для динамической статьи выбран журнал «Доклады ТУСУР» (К2, 1.2.2 по техническим наукам). Подготовлена редакция по официальному шаблону 2026 года с 15 источниками, структурированными аннотациями и повторной проверкой вычислений. [Заключение о готовности](audit/TUSUR_READINESS_2026-10-23.md) фиксирует требования MathType и авторской научной редакции в связи с правилами об ИИ. Отправка в редакцию не выполнялась.

В `articles/` теперь шесть Word-файлов для четырёх исследований. Оформления ИТВС и ТУСУР относятся к одной математической работе, как две языковые версии EJCE относятся к одной образовательной статье. Это альтернативные редакции, а не отдельные результаты для параллельной подачи.
