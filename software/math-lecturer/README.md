# ИИ-лектор по математике докторского исследования

Локальный браузерный кабинет: http://127.0.0.1:3210. Редакция 28.10.2026.

28 последовательных занятий, 44 формульных блока с пояснениями и 364 исходных фрагмента из четырёх работ. Вводный раздел объясняет вероятность, Beta-распределение, производную и обратную задачу. Затем разбираются SITITO, EJCE, INJOIT и динамическая работа в текущей редакции ПСТА. ИТВС, ТУСУР и ПСТА не считаются разными исследованиями.

## Что можно делать

- Читать подробные занятия с выводами, примерами и границами применимости.
- Слушать занятие, выбранную формулу, выделенный текст или ответ модели. В Windows используется установленный русский голос System.Speech; аудио воспроизводится с паузой и изменением скорости. Длинный текст озвучивается последовательными частями. На других системах есть запасной вариант через локальные голоса speechSynthesis браузера; сетевые голоса автоматически не выбираются.
- Задавать вопросы, просить объяснить проще, разобрать каждый символ, промежуточное преобразование, код или эксперимент. Ответ поступает постепенно; генерацию можно остановить. Браузер получает накопленные части короткими запросами: длительная работа CPU не требует одного постоянно открытого соединения. У ответа есть ссылки на фактически предоставленные фрагменты источников.
- Проводить четыре учебных эксперимента: Beta и риск; R₀/R₁/R₂; ресурсное согласование INJOIT; восстановление девяти параметров ОДУ. Последние два вызывают исходные Python-модули без перезаписи результатов статьи. Чат получает проверенный сервером результат по его идентификатору.
- Сохранять конспект с диалогом в Markdown и результаты лаборатории в JSON. Прогресс и вопросы хранятся в localStorage текущего браузера.

## Новые статьи

Откройте **Библиотека → Добавить статью или материал**. Поддерживаются PDF с текстовым слоем, DOCX, TXT, MD, TeX; для экспериментов можно загрузить CSV, JSON и текст Python/JavaScript. Один файл – до 20 МБ, библиотека – до 100 материалов. Загруженный код только читается и **никогда не исполняется**. TeX не компилируется.

Статья сразу появляется в программе, делится на части для последовательного разбора и становится доступна поиску и диалогу без перезапуска. Формулы DOCX/TeX, которые удалось извлечь, добавляются в каталог. В карточке новой части кнопка «Начать диалог с лектором» запускает подробный разбор модели; ответы можно прослушивать. Подготовленные вручную объяснения относятся к исходным четырём статьям. Для новых документов объяснение генерирует модель на основе извлечённого текста.

Длинные абзацы и тексты кода разбиваются на небольшие фрагменты без потери конца материала; формулы при разбиении сохраняются целиком. Для вопроса только о новой статье в контекст передаются её фрагменты. Исходные работы добавляются при запросе на сравнение.

Оригинал доступен из карточки статьи и источника. Извлечение сложных формул из PDF/OMML не гарантирует идеального сохранения записи: её нужно сверять с оригиналом. Для сканов требуется предварительное OCR или текстовая версия. Пример для проверки загрузки находится в `examples/upload-example.tex` и явно обозначен как учебный материал.

Файлы, извлечённый текст и аудиокэш сохраняются в `LECTURER_DATA_DIR`; по умолчанию это `private/` приложения. На текущей машине настроен диск D. Они не включаются в Git. Повторная загрузка одинакового файла определяется по SHA-256.

## Запуск на текущей машине

Запустить `start.ps1` либо файл «ИИ-лектор_Запуск.cmd» в каталоге outputs рабочего проекта. Скрипт поднимает локальный веб-сервер и, если настроен `OLLAMA_EXE`, локальный Ollama. Фоновые процессы запускаются без окон. Переменные конкретной машины записаны в `.env.local`, который не публикуется.

Node.js 24+. Зависимости: `npm install --ignore-scripts` или `pnpm install --ignore-scripts`. Затем `npm start` либо `node src/server.mjs`.

Для импорта PDF нужен Python с pypdf. Для лаборатории INJOIT достаточно стандартной библиотеки Python; для ОДУ нужны зависимости `research/diff_eq/requirements.txt` из корня репозитория. При работе из каталога приложения путь к этому файлу – `../../research/diff_eq/requirements.txt`. Настройте `PYTHON_EXE`; при использовании отдельного каталога научных библиотек укажите `RESEARCH_DEPS`. На текущей машине эти зависимости уже подключены.

## Локальная модель и другой API

По умолчанию используется **Ollama + qwen3:4b-instruct**, без платного API. На текущей машине движок и модель размещены в `D:\CodexWork\runtimes\ollama`. Веса не входят в репозиторий; условия использования модели указаны в её официальной карточке. На CPU первая обработка большого контекста может занимать минуты; подготовленные тексты, озвучка и калькуляторы работают независимо от генерации. В чате можно выбрать краткий или подробный разбор.

На другой Windows-машине можно выполнить `setup-local-model.ps1 -RuntimeRoot D:\CodexWork\runtimes\ollama`. Скрипт получает официальный переносимый дистрибутив Ollama, проверяет SHA-256 из метаданных релиза, запускает сервер и скачивает модель. Требуется несколько ГБ для скачивания и распаковки. При уже работающем Ollama модель сохраняется в каталоге, с которым запущен тот сервер.

Другой сервер настраивается в `.env.local`:

```ini
LLM_PROVIDER=openai_compatible
LLM_BASE_URL=http://127.0.0.1:8080/v1
LLM_MODEL=your-model
# LLM_API_KEY=server-side-key
```

Для внешнего сервиса в запрос попадут вопрос, часть истории и подобранные фрагменты статей. Ключ хранится только на сервере. Доступность и стоимость стороннего сервиса определяются его условиями; приложение не обещает ему бесплатный тариф. Настройки `.env.local` не передаются браузеру.

## Основание ответов и пределы

Поиск выполняется по текущему занятию, формулам, текстам, методологическому словарю, исходному коду и результатам. Тексты источников рассматриваются как данные, а не команды. Модель может вызвать два ограниченных вычислительных инструмента: Beta-калькулятор и точное сравнение правил EJCE. Лаборатории не допускают произвольного исполнения кода или команд.

Если в вопросе запрошена проверка чисел, а успешного результата инструмента или лаборатории нет, приложение показывает это отдельной отметкой: фраза модели «калькулятор подтверждает» не считается доказательством вызова. Для воспроизводимого численного разбора сначала выполните расчёт в лаборатории и нажмите «Объяснить результат по шагам».

Beta-лаборатория отдельно рассчитывает сценарии «ещё один успех» и «ещё одна неудача». Они позволяют проверить гипотезу о направлении изменения среднего и нижней границы. Если в ответе по переданному расчёту обнаружено известное обратное утверждение о снижении границы после успеха, показывается вычисленная поправка. Это локальная проверка конкретного противоречия; свободный текст модели по-прежнему сверяется с формулами и источниками.

Лектор сохраняет различия моделей: δ/m и сумма рисков; независимость для произведения и её отсутствие в неравенстве объединения; Beta и ОДУ; структурная идентифицируемость и практическое оценивание; локальная устойчивость и глобальная сходимость оптимизатора. Во всех исходных исследованиях результаты синтетические. Ответ генеративной модели не становится автоматически доказательством и требует проверки по предоставленным источникам.

Сервер слушает только 127.0.0.1; проверяет Host и Origin. Это однопользовательский локальный прототип, без облачного размещения и многопользовательской авторизации.
