# ЦОП · Прикладное машинное обучение

Пилот программного комплекса для исследования индивидуальных образовательных траекторий. Версия 0.1, 22.10.2026. Первый рабочий цикл — дисциплина «Алгоритмы и структуры данных в языке Python».

## Что работает

- PostgreSQL: миграции, 38 компетенций, 116 уникальных индикаторов; 11 карточек дисциплин 1–2 курса.
- 16 тем РПД, 48 заданий трёх уровней, версии условий и эталонов; старые попытки сохраняют свои тесты.
- Вход по учетной записи, scrypt, принудительная смена временного пароля, отзыв сессий, серверная проверка роли и учебной области.
- Кабинеты студента, преподавателя, тьютора, методиста, руководителя программы, исследователя, администратора и внешнего эксперта.
- Цикл: гипотеза → версия Python-кода → проверка → сравнение → отзыв преподавателя → журнал и свидетельства.
- Симулятор линейного/двоичного поиска и сортировок вставками/слиянием: seed, число сравнений, трасса поиска, запись опыта.
- Математическая оценка по Beta-модели: самостоятельность, независимые задачи, целевой уровень, свежесть, перенос, нижняя 95% граница. Модель рекомендательная.
- Повторяемый закрытый импорт студентов и исходных ячеек журналов с SHA-256 источника. Пароли и реальные журналы отсутствуют в репозитории.
- Локальный Python в браузере через Pyodide/Web Worker: проверки своего кода и сравниваемого варианта без Docker и CDN. Результат помечен как предварительный и не выставляет оценку. Отдельный серверный Docker runner подготовлен для следующего этапа. LLM по умолчанию отключена.

## Быстрый локальный запуск

Node.js 24+, pnpm 11.25+. Встроенный PGlite использует PostgreSQL в WASM для локальной разработки. Облачный режим использует обычный PostgreSQL через `pg` и `DATABASE_URL`.

```sh
pnpm install --frozen-lockfile
pnpm seed
# Необязательная отдельная демонстрационная БД с вымышленными пользователями:
DEMO_PASSWORD='choose-a-long-local-password' pnpm seed --demo
pnpm start
```

Открыть `http://127.0.0.1:3000`. Демонстрационные логины: `demo-student`, `demo-teacher`, `demo-tutor`, `demo-methodist`, `demo-program_manager`, `demo-researcher`, `demo-admin`, `demo-expert`. Пароль задаёт запускающий. `seed` без `--demo` не создаёт демонстрационных учетных записей. Не включать их в рабочей БД.

В PowerShell переменная задаётся отдельно: `$env:DEMO_PASSWORD='…'`, затем `pnpm seed --demo`. Для отдельной БД задать `DATA_DIR`. Реальные данные не нужны для тестирования.

```sh
pnpm test
```

## Граница пилота

Это начало разработки, а не завершённое выполнение всего ТЗ. Полное планирование восьми семестров, редактор AND/OR-графа, оптимизация нагрузки, 21 сочетание элективов, калибровка моделей, полные интеграции, расписание, окончательное покрытие компетенций и педагогический эксперимент относятся к следующим этапам. Остальные 10 карточек дисциплин пока не содержат адаптивных курсов. Метаданные семестров, помеченные как предварительные, требуют сверки с учебным планом.

Рабочая облачная БД, DNS и HTTPS будут подтверждены только после фактического развёртывания. Наличие конфигурации Docker не означает запущенный российский сервер.

Полное ТЗ с приложениями: [DOCX, версия 1.0](docs/ТЗ_ЦОП_1_0.docx). По решению заказчика сначала завершается локальная отладка; облачное создание отложено.
