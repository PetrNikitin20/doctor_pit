# Интеллектуальная система междисциплинарного обучения · ПМО

Локальный исследовательский пилот, версия 0.2 от 29.10.2026. Репозиторий программной системы: [MKRmodel](https://github.com/PetrNikitin20/MKRmodel). Научные статьи, воспроизводимые эксперименты и публичный снимок кода: [doctor_pit](https://github.com/PetrNikitin20/doctor_pit).

## Реализовано

- 43 дисциплины 1–4 курса, 72 учебные темы, 216 заданий трёх уровней. Алгоритмический курс содержит 16 тем по РПД; остальные – авторские стартовые модули для методической экспертизы.
- В семи приоритетных дисциплинах по три темы и девять заданий: математика ИИ, технологии обработки данных, алгебра и геометрия, учебно-научный семинар, рекомендательные системы, обработка естественного языка, прикладные задачи машинного обучения.
- 38 компетенций и 116 уникальных индикаторов целевой модели. Документированные связи дисциплин с КРМ отделены от авторских предложений по индикаторам, заданиям и переходам.
- Девять локальных воспроизводимых симуляторов: поиск, градиент, косинусная близость, утечка данных, множественные проверки, рекомендации, RAG-ссылки, классификация, AND/OR-граф.
- 208 кандидатных правил перехода между уровнями, темами и дисциплинами. AND-предпосылки и альтернативные правила; методическая экспертиза, проверка календаря и утверждение руководителем программы.
- Отдельная бинарная модель готовности: Beta(1+s, 1+n−s), бюджет δ/m на предпосылку, самостоятельность, сопоставимые семейства, свежесть и перенос. Оценки, исходные ячейки журналов и браузерные тесты автоматически в неё не входят.
- Личный выбор двух из семи элективных модулей. Структурный прототип проверяет фиксированный состав программы; это ещё не полный компилятор модели из статьи НГУ.
- Журналы по дисциплинам, версии решений, эксперименты, сравнения, текстовые артефакты с SHA-256 и преподавательские отзывы.
- Восемь ролей, серверные права на группы/дисциплины, временный доступ эксперта, scrypt, обязательная смена начального пароля и аудит.
- PostgreSQL-совместимая схема из 44 таблиц. Локально PGlite, для последующего облака адаптер pg.
- Pyodide/Web Worker для Python в браузере без CDN. Клиентская проверка предварительная; отдельный Docker runner подготовлен, но не развёрнут. Внешние LLM отключены.

В закрытой рабочей БД сохранены 303 студента: 149 ПМ26 и 154 ПМ25. Группы ПМ25 требуют сверки; списки 3–4 курса ещё не переданы. Персональные данные, пароли, журналы и резервные копии отсутствуют в Git.

## Запуск

Node.js 24+, pnpm 11.25+:

```sh
pnpm install --frozen-lockfile
pnpm seed
# Для отдельной синтетической демонстрационной БД:
DEMO_PASSWORD='choose-a-long-local-password' pnpm seed --demo
pnpm start
pnpm test
```

В PowerShell переменная задаётся отдельно: `$env:DEMO_PASSWORD='…'`. Демонстрационные логины: `demo-student`, `demo-teacher`, `demo-tutor`, `demo-methodist`, `demo-program_manager`, `demo-researcher`, `demo-admin`, `demo-expert`. Пароль задаёт запускающий. Для отдельной БД используется DATA_DIR; одну директорию PGlite нельзя открывать двумя процессами.

На подготовленной машине: рабочий контур http://127.0.0.1:3001, демонстрационный http://127.0.0.1:3000. Скрипты Start-Local.ps1 / Stop-Local.ps1 описаны в [локальной инструкции](docs/LOCAL.md).
