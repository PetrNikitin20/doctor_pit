# Проверки и статус ТЗ

Дата: 22.10.2026. Проверена версия из этого репозитория на Windows, Node 24.19, PGlite 0.5.11. Это PostgreSQL в WASM, не проверка подключённого облачного PostgreSQL и не нагрузочное испытание.

## Выполнено

25 автоматических сценария `pnpm test`: повторяемые миграции/seed, анонимный доступ, cookie/секреты, CSRF, RBAC, сокрытие эталонов и ожидаемых ответов, обязательная гипотеза, воспроизводимость симуляции, неизменность версий и откат конфликта, честный статус отсутствующего runner, происхождение сравнения и отключённая LLM, защита чужого журнала, области преподавателя, запрет оценивания тьютору, транзакция отзыва, методическое утверждение, Beta-критерий/свежесть/независимость/уровни, временный доступ эксперта, сохранение старых тестов, исследовательская агрегация, обязательная смена пароля и повторный импорт. Дополнительно: локальная регистрация результатов Python, отдельная CSP Worker и экспорт закрытой резервной копии только администратором.

Все 48 авторских Python-эталонов отдельно проверены на 112 примерах. Это проверка подготовленных материалов доверенным скриптом, а не запуск присланного студентом кода на хосте.

Браузерная проверка: вход демонстрационного студента, навигация по темам, сохранение гипотезы и версии, симуляция, сравнение, журнал. Pyodide выполнил корректное решение, CSP заблокировала чтение API из учебного кода; бесконечный цикл остановлен через 4 секунды. Собственное решение и эталон проверяются на одних примерах. Рабочие учетные записи администратора и студента проверены локально с обязательной сменой временного пароля. Снимок 38 таблиц/5 245 строк восстановлен без различий. Linux Docker runner не запускался.

## Перед рабочим запуском

Сверить ПМ25 и номера групп, назначить сотрудников, утвердить семестры/РПД/связи индикаторов, развернуть PostgreSQL/runner в РФ, проверить ограничения Docker, восстановление дампа, HTTPS и доступность из РФ. Сохранить действующие данные УМНИК перед переключением edu-домена. Установить оператора данных, эксплуатационные роли и условия хранения. Научную эффективность исследовать отдельно от технической работоспособности.

Пилот не выдаёт завершение всех компетенций или готовность к переводу на следующий курс по одному алгоритмическому заданию.
