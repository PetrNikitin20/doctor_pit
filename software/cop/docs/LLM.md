# Бесплатные LLM

Система работоспособна без LLM. По умолчанию `LLM_PROVIDER=disabled`. Методический эталон отмечается как эталон, а не сгенерированный ответ.

| Режим | Подключение | Ограничения |
|---|---|---|
| Ollama в своём контуре РФ | `LLM_PROVIDER=ollama`, `LLM_BASE_URL=http://ollama:11434/v1`, модель в `LLM_MODEL` | Сам API без платы за токены; нужны вычислительные ресурсы. На ВМ портала 4 ГБ большая модель не планируется |
| OpenAI-совместимый API | `LLM_PROVIDER=openai_compatible`, URL `/v1`, ключ и модель в окружении | Бесплатная квота зависит от провайдера; нельзя обещать постоянную бесплатность или доступность из РФ |
| OpenRouter free | Тот же адаптер, `https://openrouter.ai/api/v1`, разрешённая free-модель | В открытом тарифе указаны 50 запросов/день для бесплатных моделей; это внешний контур, без гарантированного SLA |
| GigaChat | Нужен отдельный OAuth-адаптер | В пилоте не реализован; условия физлиц и некоммерческого использования необходимо согласовать с оператором образовательной системы |

По каждому запросу пользователь отдельно подтверждает согласие. Реализованный адаптер передаёт **только публичное условие задачи**, без ФИО, группы, журнала, оценки, пользовательского кода и учетных данных. Ответ сохраняется с провайдером, моделью и хешем запроса. LLM не пишет оценки и не определяет допуск. Ошибка квоты не отменяет сохранённую работу. Автоматического перехода на платного провайдера нет.

Для локального Ollama использовать `OLLAMA_NO_CLOUD=1`, закрытую сеть и предварительную загрузку разрешённой модели. Возможный вариант — Qwen2.5-Coder 7B (Apache 2.0); требование порядка 8–16 ГБ RAM является инженерной оценкой, а не гарантией. Проверить фактическую память и задержку на выбранной машине.

Проверенные первичные источники:

- [Ollama: OpenAI compatibility](https://docs.ollama.com/api/openai-compatibility)
- [Ollama FAQ: local/cloud](https://github.com/ollama/ollama/blob/main/docs/faq.mdx)
- [Qwen2.5-Coder 7B: карточка модели](https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct)
- [OpenRouter: тарифы](https://openrouter.ai/pricing/), [политики провайдеров](https://openrouter.ai/docs/guides/privacy/provider-logging)
- [GigaChat: условия физлиц](https://developers.sber.ru/docs/ru/policies/gigachat-agreement/individuals), [тарифы](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs)

Условия и квоты меняются. Перед подключением проверяются действующий тариф, регион обработки и доступность, а ключи остаются только на сервере. Использование бесплатного зарубежного API не соответствует утверждению «вся обработка выполняется в РФ».
