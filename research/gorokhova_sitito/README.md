# Методическая статья Р И Гороховой для SITITO

Согласованное название: «Дифференцированное обучение алгоритмам и структурам данных на основе компетентностной модели и цифрового симулятора».

Авторская редакция от 29.10.2026 подготовлена для чтения и согласования Риммой Ивановной Гороховой. Статья не отправлялась и не обозначается принятой. Педагогический эксперимент по решению заказчика относится к следующему этапу.

## Материалы

- Word находится в articles/Горохова_Дифференцированное_обучение_алгоритмам_SITITO_2026-10-29.docx.
- article_readable.md – читаемый текст с таблицами и литературой.
- manuscript.md, front_matter.json, tables.json – редактируемые источники.
- bibliography_metadata.json – 27 отобранных научных публикаций с DOI и сведениями проверки, включая две статьи DigiTarin.
- demonstration_results.json и reproduce_examples.mjs – новые демонстрационные расчёты по зафиксированному публичному коду системы. Данные студентов не используются.
- figure_cycle.svg и figure_cycle.png – исходник схемы и изображение для Word.
- build_article.py – сборка на основе предоставленного шаблона; template_contract.md фиксирует сохранённые компоненты и осознанные изменения.
- verify_article.py, build_audit.json и validation.json – проверки чисел, оформления и происхождения.
- source_manifest.json – контрольные суммы исходных методических документов. Сами шаблон, РПД и КРМ не публикуются.

## Воспроизведение

В корне doctor_pit:

```text
node research/gorokhova_sitito/reproduce_examples.mjs
python research/gorokhova_sitito/build_article.py --template ПУТЬ_К_sitito_template.docx --output articles/Горохова_Дифференцированное_обучение_алгоритмам_SITITO_2026-10-29.docx
python research/gorokhova_sitito/verify_article.py
```

Сборка требует lxml и Pillow; для нового рисунка используется prepare_materials.py. Генератор библиографии обращается к первичному реестру DOI и не заменяет редакторский отбор источников. Готовые выбранные метаданные сохранены, сеть для обычной сборки не нужна.

Числа сравнения сортировок проверяются независимым Python-подсчётом: для вставок по рангам префиксов, для слияния снизу вверх. Округления не интерпретируются как статистические оценки. Проверка использует конкретный зафиксированный снимок MKRmodel и не перезаписывает прежние научные эксперименты.

После изменения DOCX необходимо повторить экспорт Word только для чтения и визуально проверить все страницы. Путь к шаблону и локальные средства визуальной проверки в verify_article.py настроены на авторскую рабочую машину; при переносе их следует явно актуализировать. Успех автоматических проверок не заменяет визуального просмотра.

Перед отправкой следует закрыть вопросы из [заключения готовности](../../audit/GOROKHOVA_SITITO_READINESS_2026-10-29.md).
