# Редакция для Докладов ТУСУР

«Идентификация динамической модели междисциплинарной подготовки при внешней поддержке», П.В. Никитин. Авторская проверка от 23 октября 2026 года. Это альтернативное оформление той же работы, что и ИТВС, а не отдельное исследование для параллельной подачи.

Рукопись: 7 страниц, 22 смысловых блока формул, 3 таблицы, один рисунок с двумя панелями, 15 источников. Восемь источников датированы 2022–2026 годами. Полный основной текст на русском, метаданные и References также на английском. DOI статьи, том и номер выпуска не присваиваются автором.

## Повторная сборка

Официальный шаблон необходимо получить с сайта редакции; он не распространяется вместе с кодом:

https://journal.tusur.ru/storage/189688/Shablon-2026-5.docx

SHA-256 исследованного файла: `f4d40c38fc54640978e1a800fc559b3678d98403c6edf1b8c16f5dd9bc2d9f20`.

```bash
python -m pip install -r requirements.txt
python -m pip install -r ../../tools/requirements-authoring.txt
python retarget_tusur.py --template PATH/TO/Shablon-2026-5.docx --output PATH/TO/Никитин_Доклады_ТУСУР.docx
```

Команды выполняются из `research/diff_eq`. Нужен Microsoft Office `MML2OMML.XSL`; иной путь передается аргументом `--xsl`. В оформлении используются исходные стили и геометрия шаблона, а не общий стиль документов. Отступления по авторскому указанию: таблицы без заливки, все границы видимы, длинное тире заменено средним. Колонтитулы содержат автора и название журнала без вымышленных реквизитов выпуска.

`manuscript_itvs.json` сохранен как предыдущий текст. Сборщик создает `manuscript_tusur.json`, добавляет ссылки в конкретные методологические положения и последовательно перенумеровывает библиографию. В определителе полностью поддерживаемой калибровки исправлено оставшееся обозначение q на κ = exp(−λh). Изменения математической модели и численных результатов не вносились.

`equations_tusur.tex`, `equations_tusur.json` и `mathml_tusur/` содержат все 22 формулы для последующего переноса в MathType. Файл `conditioning_tusur.svg` допускает редактирование графика; PNG используется в Word для совместимости. Исходные данные рисунка – `results.json`.

## Проверка вычислений

```bash
python experiment.py
```

Повторный запуск выполняется с зафиксированными версиями зависимостей. Проверка 23.10.2026 дала побайтное совпадение `results.json` и всех четырех CSV с сохраненными исходными файлами. Проверены 80 восстановлений, независимое интегрирование исходных ОДУ и 180000 статистических повторений калибровки. Подробности и контрольные суммы находятся в `audit/tusur_validation.json` относительно корня репозитория.

Воспроизводимость вычислений не подтверждает образовательную эффективность и не заменяет содержательную авторскую проверку новизны.

## Статус перед отправкой

В текущем DOCX используются редактируемые Word Equation, а журнал требует MathType. Наличие в исходном шаблоне демонстрационных OLE-объектов не означает конвертацию формул рукописи. Готовность к отправке не заявляется. Также необходимо соблюдать правила журнала об ИИ и оформить авторские сопроводительные документы. Полное заключение: `audit/TUSUR_READINESS_2026-10-23.md` в корне репозитория.
