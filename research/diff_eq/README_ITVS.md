# Воспроизводимые расчёты к статье для ИТВС

«Идентификация динамической модели междисциплинарной подготовки при внешней поддержке»

В пакете находятся исследовательская программа, зависимости с версиями, полные синтетические результаты, четыре таблицы CSV, график и структурированный текст рукописи. Данные студентов не входят в пакет.

## Запуск

Для зафиксированных версий зависимостей требуются Python 3.12 или новее и отдельное виртуальное окружение. Расчёт выполнен на Python 3.12.14. Установите зависимости из requirements.txt, затем выполните:

```
python experiment.py
python make_figure.py
```

Генератор использует seed 20261022. results.json, exact_recovery.csv, conditioning.csv, binomial_calibration.csv и transfer_excitation.csv создаются в каталоге программы. Повторный запуск перезаписывает только эти результаты в каталоге извлечённого пакета.

## Состав проверки

- 40 случайных векторов параметров, два режима наблюдения M и A, всего 80 восстановлений.
- Прямая задача сравнивается с независимым интегрированием исходных ОДУ методом DOP853.
- Два определителя калибровки проверяются символьно.
- Исследуются наименьшие сингулярные числа калибровочного и полного якобианов, а также вырождение переноса при почти постоянной предпосылке.
- 18 конфигураций биномиальной калибровки, по 10000 повторений на конфигурацию, всего 180000 троек частот. Недопустимые для прямого обращения частоты фиксируются в отчёте.

## Интерпретация

Точные вероятности в теореме не являются единичными бинарными ответами. Статистическая часть предполагает фиксированное состояние внутри каждой калибровочной ячейки. Это идеализированная вычислительная проверка; применение к реальным учебным событиям требует отдельной наблюдательной модели.

Неудача замкнутой формулы калибровки не доказывает невозможность ограниченного оценивания методом максимального правдоподобия. Условные ошибки среди допустимых оценок следует читать вместе с долей недопустимых повторений.

## Файлы рукописи

manuscript_itvs.json содержит текст, формулы в TeX-нотации и библиографию. Основная рукопись для редактирования предоставлена отдельно в DOCX; математические выражения в ней представлены объектами Word Equation. qa_itvs.json фиксирует структурные и численные проверки. SHA256SUMS.json содержит контрольные суммы файлов пакета.

Целевой журнал: «Информационные технологии и вычислительные системы», рубрика математического моделирования, 1.2.2 по техническим наукам, К1. Резерв по 1.2.1 – «Искусственный интеллект и принятие решений». Основания выбора и открытые научные вопросы приведены в отдельной записке.
