# Воспроизведение численного эксперимента

Python 3.12; зависимости из requirements.txt. После установки выполнить python experiment.py. Программа заново записывает JSON и четыре CSV в свой каталог. Это синтетическое исследование: 80 восстановлений и 180000 повторений биномиальной калибровки. Seed 20261022. Персональные данные не используются.
