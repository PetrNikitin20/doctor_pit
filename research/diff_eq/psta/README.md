# Исходники статьи для журнала Программные системы теория и приложения

Редакция от 24 октября 2026 года. Рубрика 6 «Математическое моделирование», специальность 1.2.2, технические науки.

article.tex использует официальный класс psta.cls с опцией blind. Она скрывает сведения об авторе в PDF; исходный TeX содержит авторские метаданные для редакции. Класс и каталог psta загружены из https://psta.psiras.ru/publ-conditions/psta.zip без изменений. Это издательские файлы.

В преамбуле определен отсутствующий в классе макрос HideFromPeer@ для анонимного режима; колонтитулы заменены нейтральными через pstamarkboth. Класс не редактировался. raggedbottom предотвращает растяжение последней страницы библиографии.

Сборка: три запуска pdflatex -interaction=nonstopmode -halt-on-error article.tex в этом каталоге. В Windows можно запустить build.ps1 при доступном pdflatex.

До рецензирования отправляется анонимный PDF. Персональные сведения передаются в сопроводительном письме. Для публикационной версии автор предоставляет фотографию. Авторская справка заверяется по месту работы. Теоретический результат и расчетные JSON/CSV сохранены из предыдущей редакции; рисунок пересобран в векторном формате на тех же числах.

Это альтернативное оформление той же работы, ранее подготовленной для ИТВС и ТУСУР, а не новая публикация. Материалы не обозначаются как принятые или опубликованные в этих журналах.

Для корректных русских переносов требуются hyphen-russian и форматы TeX, пересобранные после установки языковых пакетов.
